Compatibility

Check the registered relationship between equipment and resources before you submit a request. Compatibility is an information tool: it shows what your system has recorded, including compatible and incompatible pairings.

How to use Compatibility

1SearchType an equipment or resource name to find matching records.
2FilterUse the relationship filter to show compatible or incompatible records.
3ReviewRead the pair and notes before deciding what to request.
4ContinueUse View equipment to open the equipment record and continue your normal request flow.

What the status means

CompatibleThe database records this equipment/resource pairing as compatible.
IncompatibleThe database records this pairing as incompatible, so review it before requesting the equipment.

Compatibility does not create a request or change inventory. It is a reference check that uses the records already stored in ÆTHERYX.
